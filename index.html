ABOUT THIS PROJECT

From a book to a living encyclopedia.

Hemplopedia began as a published reference book by Willis Butts. This online edition preserves its topic directory and provides paths to articles, images, and videos about each subject.

Each topic includes an introductory document and an illustration. In-depth, independently researched articles are an ongoing project. External search results may require verification.
